# AI 使用说明

[English](AI_USAGE.md) | 简体中文

## 由开发者确定的方向

开发者确定了产品范围、三种密码模式、参数边界与默认值、三键交互、离线与隐私要求、MoonBit 优先架构、目标硬件、构建产物、测试要求、文档集合，以及不得把构建成功描述为真机成功的规则。

## AI 协助内容

AI 协助检查官方仓库与硬件约束，调查 MoonBit native/C FFI 路径，实现 MoonBit 与 C 代码，生成紧凑词库和 CJK 字体子集，编写测试与文档，并根据真实编译和验证输出定位问题。

AI 生成或修改的代码通过源码检查与可执行门禁复核。编译错误按真实诊断处理，没有虚构成功结果。开发者仍需负责代码审查、设计解释、真机验收，并决定是否正式提交或发布 Hackathon 项目。

## 验证方式

- MoonBit check 将 warning 视为失败。
- 139 个确定性 MoonBit 测试覆盖生成策略、边界、字符类别、输出后置校验、Passphrase 格式、词库索引、拒绝采样、状态转换、输入手势、结果生命周期、视图模型、电池策略、强度分级、声音波形，以及 FAP_SCREENSHOT_V1 命令匹配状态机、应答协议头构建、快照几何校验、条带顺序状态机、整帧记账与故障词汇表；其分布为可移植根库 12 项、CLI 3 项、浏览器命令 2 项、独立模块消费者 2 项、固件适配层 120 项。25 项 Python 主机测试覆盖截屏工具的协议头解析、RGB565 转换与 PNG 写出、固件布局校验器以及编译器版本门禁。
- 报名因 MoonBit 代码不足 1,000 行被驳回后，AI 协助把可独立测试的产品逻辑从 C 迁到 MoonBit；当前代码树实测有效生产 MoonBit 为 3,821 行（根库 775 行 + 固件适配层 3,046 行），按同一规则统计的测试有效行为 2,202 行；`python tools/check_repo.py` 会直接打印生产有效行数，门禁下限为 1,000。
- ESP-IDF 5.5.3 将生成的 MoonBit C 实际编译进 ESP32-C3 应用；串口截屏改走面板 `draw_bitmap` 抽头按 240x20 条带采集，`CONFIG_LV_USE_SNAPSHOT` 已不再是该路径的依赖，仅在其被移除前暂时保留。
- 合并镜像验证器检查 bootloader、分区表、应用偏移、分区容量及完整 `-full.bin`。
- 条带流式构建（`46a370e`）已烧录到真实 AI Passport，启动到 `Ready: secure_random=1 buttons=1 ble_keyboard=1` 并以 `FoloPassKey` 广播；抓回的面板帧中文字模与凭据界面渲染正确、条带边界无接缝，且键盘保持广播期间可连续应答 `FAP_SCREENSHOT_V1`。以 `0x0` 写合并镜像会重置 NVS，因此设置项从默认值加载。仍未真机验证：与真实主机的配对、HID 输入、三键手势、设置页、重启后的偏好保留、声音开关与电池行为。旧镜像曾报告中文笔画偏细以及 77%、不充电冷启动 0% 的电量读数，本次未复测这两项。该构建之上的配对看门狗与标签字模两个补丁只有宿主机测试与一次干净的固件构建作为证据，新镜像尚未烧录到设备。

## 人工复核清单

Hackathon 提交前，开发者应检查 RNG 初始化顺序与失败行为，阅读状态机测试，在真机确认全部 UI 文案，验证三键流程，复核第三方声明，并从干净 checkout 复现两条验证命令。
